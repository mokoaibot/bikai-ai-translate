# BIKAI — полный каталог 2026 (RU)

Русская версия каталога аналитических приборов BIKAI, свёрстанная **по шаблону оригинальной
английской брошюры**: та же сетка и формат страницы, фирменная палитра, обложка, страница
содержания, колонтитулы и нумерация.

| | |
|---|---|
| Готовый файл | [`output/BIKAI_Каталог_2026_RU.pdf`](output/BIKAI_Каталог_2026_RU.pdf) — 35 страниц, 8,5 МБ |
| Формат страницы | 216 × 291 мм (как в оригинале — 612 × 825 pt) |
| Шрифты | Montserrat + Inter (полная кириллица), встроены в PDF |
| Исходники | папка [`source/`](source) |

## Что внутри

* Обложка по оригинальному макету (логотип, `ПОЛНЫЙ КАТАЛОГ 2026`, синяя полоса, фото).
* Страница «Содержание» с нумерованными «пилюлями» разделов; номера страниц считаются
  автоматически по якорям PDF.
* 8 разделов: компания и контакты → жидкостная хроматография → масс-детекторы →
  генерация азота → модули и детекторы ВЭЖХ → сбор фракций и ГХ-автосэмплер →
  ChromCore → типовые применения.
* 29 рисунков и 26 таблиц из перевода; 15 таблиц — в основном тексте, 11 —
  в приложении А.
* **Приложение А.** Расшифровка надписей на рисунках (двуязычный глоссарий:
  рисунки оставлены в исходном виде, подписи на них английские).
* **Приложение Б.** Примечания переводчика — замечания к опечаткам и спорным местам
  исходного макета (в основном тексте на них стоят ссылки).

## Структура репозитория

```
source/   исходные файлы: оригинальная брошюра (EN, PDF) и чистовой перевод (RU, DOCX)
assets/   логотип, фото обложки, шрифты, рисунки (извлечены из исходников автоматически)
tools/    сборочный конвейер
output/   готовый PDF
build/    промежуточные файлы (в git не попадает)
```

## Как пересобрать

```bash
pip install weasyprint pymupdf python-docx pillow

python3 tools/extract_content.py   # DOCX -> build/content.json + assets/figures/*
python3 tools/fit.py               # подбор плотности разделов (build/density.json)
python3 tools/render.py            # HTML + PDF -> output/BIKAI_Каталог_2026_RU.pdf
```

`tools/extract_content.py` разбирает DOCX по стилям (заголовки, списки, таблицы, рисунки),
`tools/render.py` собирает HTML по шаблону `tools/style.css` и печатает его в PDF через
WeasyPrint, `tools/fit.py` измеряет заполненность страниц и автоматически уменьшает рисунки
и таблицы в разделах, которые «переползают» на лишнюю страницу с почти пустым хвостом.

## Замечания

* Тексты и таблицы взяты из файла перевода без смысловых правок; орфография и
  терминология сохранены. Примечания переводчика и таблицы «текст на картинке → перевод»
  вынесены в приложения, чтобы основной каталог читался как чистовой коммерческий документ.
* Рисунки — из исходного DOCX/брошюры, поэтому надписи на них английские
  (см. приложение А).
* Шрифт оригинала (Alibaba PuHuiTi) недоступен по лицензии — заменён на Montserrat/Inter,
  близкие по пластике и с полной поддержкой кириллицы.
